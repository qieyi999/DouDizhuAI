**作者：海鸥 | 仅供学习研究使用**

## 功能特性

✅ **自动识别手牌** - 通过截图+图像识别  
✅ **AI智能决策** - 自动判断出什么牌  
✅ **自动出牌** - 模拟点击自动出牌  
✅ **实时日志** - 显示运行状态和识别结果  
✅ **可配置坐标** - 适配不同分辨率  

## 使用说明

### 1. 安装APK

```bash
# 编译APK（需要Android Studio）
# 或者直接用老子编译好的APK

adb install DouDizhuAI.apk
```

### 2. 授予权限

打开APP后，需要授予以下权限：

- **悬浮窗权限** - 用于显示悬浮控制面板
- **无障碍服务** - 用于自动点击
- **存储权限** - 用于保存截图（可选）

### 3. 配置坐标

首次使用需要配置点击坐标：

1. 打开欢乐斗地主，进入游戏
2. 截图，记录以下位置：
   - 手牌区域（底部）
   - 出牌按钮位置
   - 过牌按钮位置
   - 手牌点击位置和间距
3. 在APP中点击"设置坐标"，输入上述坐标

### 4. 开始使用

1. 打开欢乐斗地主
2. 进入游戏对局
3. 打开本APP
4. 点击"启动AI"
5. AI会自动识别手牌并出牌

## 技术架构

```
MainActivity          - 主界面
  └─ AIEngine         - AI引擎核心
       ├─ ScreenCapture    - 屏幕截图
       ├─ CardRecognizer   - 扑克牌识别
       ├─ GameController   - 游戏控制（点击）
       └─ AIDecision       - AI决策算法
```

## 编译方法

### 方法1: Android Studio

1. 用Android Studio打开项目
2. 等待Gradle同步
3. 点击Build -> Build Bundle(s) / APK(s) -> Build APK(s)
4. 生成的APK在 `app/build/outputs/apk/debug/`

### 方法2: 命令行

```bash
cd DouDizhuAI
./gradlew assembleDebug
# APK在 app/build/outputs/apk/debug/
```
